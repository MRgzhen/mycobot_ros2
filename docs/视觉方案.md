# 视觉

> 对比对象：图示两种视觉感知框架 vs 本项目（mycobot_ros2）实际采用的方案

## 一、传统视觉框架

### 1.1 图示通用流程

```
RGB/RGB-D 图像 → 滑动窗口 → SIFT/HOG 特征提取 → SVM 分类 → 识别结果
```

| 环节 | 可选方案 | 说明 |
|---|---|---|
| 候选区域 | 滑动窗口 | 遍历图像多个位置/尺度 |
| 特征提取 | SIFT、HOG | 人工设计的手工特征 |
| 分类器 | SVM 等传统机器学习 | 对特征做分类判决 |

**特点**：依赖人工设计特征，各步骤独立，无需大量标注数据和 GPU。

### 1.2 本项目方案：3D 点云几何感知（同属传统路线）

```
RGB-D 点云 → RANSAC 平面分割（去桌面）→ 欧式聚类（分物体）
→ 法线/曲率/RSD 特征估计 → 3D→2D 投影
→ RANSAC 直线/圆拟合 + Hough 变换投票 → 拟合圆柱/长方体
→ 输出形状 + 位姿给 MoveIt 抓取
```

| 环节 | 采用方案 | 代码位置 |
|---|---|---|
| 预处理 | 直通滤波、RANSAC 平面分割 | plane_segmentation.cpp |
| 物体分离 | 欧式聚类 | cluster_extraction.cpp |
| 特征估计 | 法线、曲率、RSD | normals_curvature_and_rsd_estimation.cpp |
| 模型判决 | RANSAC 拟合 + Hough 投票 | object_segmentation.cpp |
| 输出 | 圆柱体/长方体形状 + 6D 位姿 | → MoveIt 碰撞对象 |

## 二、深度学习框架（本项目未采用）

### 2.1 Two-stage（两阶段）

先生成候选区域，再对区域分类回归。精度高、速度慢。

| 方案 | 演进特点 |
|---|---|
| R-CNN | Selective Search 提区域 + CNN 逐个提特征 + SVM 分类 |
| Fast R-CNN | 共享卷积特征 + ROI Pooling，一次前向传播 |
| Faster R-CNN | RPN 网络生成候选区域，实现端到端 |

### 2.2 One-stage（单阶段）

直接在特征图上回归边界框和类别。速度快、可实时。

| 方案 | 特点 |
|---|---|
| SSD | 多尺度特征图直接预测 |
| YOLO 系列 | 单次前向传播，实时检测 |

## 三、方案对比

| 维度 | 传统框架 | 深度学习框架 |
|---|---|---|
| 特征来源 | 人工设计（SIFT/HOG/几何特征） | 神经网络自动学习 |
| 数据需求 | 少或无需训练数据 | 需大量标注数据 |
| 算力要求 | 低，CPU 可运行 | 高，通常需 GPU |
| 泛化能力 | 场景受限、参数敏感 | 泛化能力强 |
| 输出 | 类别/几何形状+位姿 | 类别+边界框(+掩码) |
| 本项目 | ✅ 采用（点云几何版） | ❌ 未使用 |



## 四、结论

本项目在图示两类技术中属于**传统视觉框架**，具体实现为基于 PCL 的
**3D 点云几何感知**（RANSAC + 欧式聚类 + 几何特征 + Hough 投票），
未使用任何深度学习方法（全工作空间无 YOLO/SSD/R-CNN/Torch 等痕迹）。



  1. 传统视觉（推荐入门）
     颜色/轮廓分割找物体质心，简单可靠，适合纯色物体在简单背景上，OpenCV 即可
   2. AprilTag/ArUco 标签
      给物体贴标签码，直接得到 6DOF 位姿，最稳定，适合快速验证抓取流程
   3. 深度学习检测
      YOLO 之类的目标检测，能识别任意物体但需要训练/标定，复杂度高
